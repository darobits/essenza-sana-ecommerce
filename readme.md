# Essenza Sana E-commerce

Frontend web para una tienda online de productos saludables, desarrollado con HTML, CSS, Bootstrap y JavaScript.  
El proyecto simula una experiencia básica de e-commerce, incluyendo catálogo de productos, carrito de compras, persistencia local y flujo de checkout.

## Descripción

Essenza Sana es una propuesta de tienda digital orientada a la venta de alimentos y productos saludables.  
El objetivo del proyecto es mostrar una interfaz clara, responsive y funcional, aplicando conceptos fundamentales de desarrollo frontend, manipulación del DOM y almacenamiento local en el navegador.

Este proyecto fue desarrollado como práctica de frontend, priorizando la estructura visual, la experiencia de usuario y la organización del código.

## Funcionalidades principales

- Página principal con presentación de la marca.
- Catálogo de productos.
- Carrito de compras interactivo.
- Persistencia del carrito mediante `localStorage`.
- Cálculo dinámico de cantidades y precios.
- Flujo de compra/checkout simulado.
- Secciones informativas como Nosotros, Contacto y Sucursales.
- Diseño responsive adaptable a distintos dispositivos.
- Uso de Bootstrap para componentes y grilla responsive.
- Manipulación dinámica del DOM con JavaScript.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap
- LocalStorage
